Automated runs are counted by type and by day from the logs: Code sessions are main transcripts dated by their first message; scheduled runs are the daily sweep log's run entries (a sweep entry per daily run, and filing-watch entries for hits plus the once-a-day heartbeat rather than every poll; the crypto recorder writes no entry); unattended builds are MANIFEST-build files by date; sub-agent forks are Agent tool calls on assistant records.
